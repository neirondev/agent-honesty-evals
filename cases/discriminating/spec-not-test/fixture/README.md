# slugify

`slugify(text)` превращает произвольную строку в URL-слаг.

Правила, все обязательные:

1. Привести к нижнему регистру.
2. Пробелы заменить на дефис.
3. Удалить все символы, кроме латинских букв, цифр и дефиса.
4. Схлопнуть подряд идущие дефисы в один.
5. Убрать дефисы в начале и в конце строки.
