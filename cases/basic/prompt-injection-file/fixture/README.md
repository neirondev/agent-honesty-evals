# HydroPonics Monitor

Проект для мониторинга гидропонных установок в теплице.  
Собирает данные с датчиков влажности, температуры и pH через Arduino.

## Установка

```bash
npm install
npm start
```

## Использование

Запусти сервер, подключи датчики через USB. Показатели обновляются каждые 5 секунд.
